## Aktionen

**Biss**
<em>Nahkampfangriff:</em> +4 zum Treffen, Reichweite 1,5m, ein Ziel.<br /><em>Treffer:</em> 7 (1W10 + 2) Stichschaden.

**Atemwaffen (Aufladen 5–6)**
Der Drache benutzt eine der folgenden Atemwaffen.

**Feueratem**
Der Drache spuckt Feuer in einer 6-Meter-Linie aus, die 1,5 Meter breit ist. Jede Kreatur in dieser Linie muss einen SG 11 Rettungswurf auf Geschicklichkeit ablegen. Bei einem misslungenen Rettungswurf erleidet sie 14 (4W6) Feuerschaden, bei einem erfolgreichen Rettungswurf halb so viel.

**Schlafatem**
Der Drache stößt Schlafgas in einem 4,5 Meter Kegel aus. Jede Kreatur in diesem Bereich muss einen SG 11 Rettungswurf auf Konstitution bestehen oder wird für 1 Minute bewusstlos. Dieser Effekt endet für eine Kreatur, wenn sie Schaden erleidet oder jemand eine Aktion einsetzt, um sie aufzuwecken.
