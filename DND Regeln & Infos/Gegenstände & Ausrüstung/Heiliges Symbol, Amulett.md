Ein heiliges Symbol ist eine Darstellung einer Gottheit oder eines Pantheons. Es könnte ein Amulett sein, das ein Symbol darstellt, das eine Gottheit repräsentiert, das gleiche Symbol sorgfältig eingraviert oder als Emblem auf einem Schild eingelegt, oder ein kleines Kästchen, das ein Fragment einer heiligen Reliquie enthält. Anhang PH-B "Fantasy-Historische Pantheons" listet die Symbole auf, die üblicherweise mit vielen Göttern im Multiversum verbunden sind. Ein Kleriker oder Paladin kann ein heiliges Symbol als einen Zauberfokus verwenden. Um das Symbol auf diese Weise zu verwenden, muss der Zaubernde es in der Hand halten, es sichtbar tragen oder auf einem Schild mit sich führen.
