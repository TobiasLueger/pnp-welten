## Eigenschaften

**Sturmangriff**
Wenn sich das Wildschwein mindestens 6 Meter geradeaus auf ein Ziel zubewegt und es dann im selben Zug mit einem Stoßzahnangriff trifft, erleidet das Ziel einen zusätzlichen Hiebschaden von 3 (1W6). Wenn es sich bei dem Ziel um eine Kreatur handelt, muss sie einen SG 11 Rettungswurf auf Stärke bestehen oder sie wird niedergeschmettert.

**Unermüdlich (Lädt sich nach einer kurzen oder langen Pause wieder auf)**
Wenn das Wildschwein 7 oder weniger Schaden erleidet, der es auf 0 Trefferpunkte reduzieren würde, wird es stattdessen auf 1 Trefferpunkt reduziert.
